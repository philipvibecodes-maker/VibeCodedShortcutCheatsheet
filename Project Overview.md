# Project Overview

## Overview
Shortcut Cheatsheet is desktop application to makes using your computer with a keyboard easier.
It does this by displaying keyboard shortcuts for the currently focused application.

The goal is to make using your keyboard easier, so Shortcut Cheatsheet is designed with a keyboard first UI.
Everything can be done without a mouse, there are lots of mnemonics, and we use sensical default keybinding.

## Requirements
The app assumes
* it is running on Ubuntu 24 with Gnome and Wayland.
* the user has installed the gnome extension "window-calls."

## Broad functionality
* The application will
  * open a "cheatsheet" window on launch that displayed keyboard shortcuts for the focused window
  * have seperate settings window to add, remove, and edit shortcuts
